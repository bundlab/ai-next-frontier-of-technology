# Contributing to AI: The Next Frontier of Technology

Thank you for your interest in contributing to **AI: The Next Frontier of Technology — Engineering Systems for the Autonomous Era**!

This repository serves as an open-source technical reference, guide, and codebase for software engineers and system architects. We welcome community contributions including content refinements, technical error corrections, architectural diagram updates, and runnable code examples.

---

## 🤝 How Can You Contribute?

### 1. Fixing Errors or Improving Documentation
* **Typos & Formatting:** Correct spelling, grammatical errors, broken Markdown links, or inconsistent formatting in chapters.
* **Technical Accuracy:** Suggest corrections or updates to technical concepts, framework APIs, or architecture patterns.

### 2. Code Examples & Architecture Patterns
* **Runnable Examples:** Contribute executable Python or TypeScript code snippets to the `examples/` directory (`agent_patterns/`, `rag_pipelines/`, `eval_frameworks/`).
* **Framework Updates:** Keep code examples up-to-date with current AI library versions and design practices.

### 3. Chapter Enhancements
* Propose additions to chapter outlines or suggest additional real-world case studies and architectural failure modes.

---

## 🚀 Workflow for Contributions

1. **Fork the Repository:** Create your own copy of the repository on GitHub.
2. **Create a Feature Branch:**
   ```bash
   git checkout -b docs/fix-ch01-typos
   # or for code examples:
   git checkout -b feat/add-rag-reranking-example
    ```
1. **Commit Your Changes:** Write clear, concise commit messages following convention:

    - docs(ch01): fix typo in deterministic logic section
    - feat(examples): add hybrid search implementation for chapter 4
    - fix(links): repair relative paths in README table of contents
    
2. **Push to Your Fork:**
    ```bash
    git push origin docs/fix-ch01-typos
    ```
3. **Open a Pull Request:** Submit a PR targeting the main branch with a clear description of the changes made and why they are necessary.

## 📝 Writing & Coding Standards

- **Markdown Style:** Use clear headers `(#, ##, ###)`, list formatting, and explicit syntax highlighting in code blocks.
- **Code Quality:** All code examples in examples/ must be self-contained, commented, well-typed (e.g., type hints in Python), and functional.
- **Tone:** Maintain an engineering-focused, professional, and practical tone suitable for senior software developers and software architects.

## 📜 Code of Conduct
Please treat all contributors with respect, empathy, and constructive feedback. We aim to foster a collaborative and welcoming environment for tech builders worldwide.

Thank you for helping build the definitive architectural guide for the autonomous era!
